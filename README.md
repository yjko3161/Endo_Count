# Endo_Count
내시경 검사일지 집계 시스템

1. 실행 방법
라이브러리 설치: 아직 streamlit과 pandas가 설치되지 않았다면, 터미널(명령 프롬프트)을 열고 아래 명령어를 실행하세요.

pip install streamlit pandas
파일 저장: 위에 제공된 코드를 복사하여 app.py라는 이름의 파일로 저장합니다.

앱 실행: 터미널에서 app.py 파일이 저장된 폴더로 이동한 후, 다음 명령어를 입력하세요.

streamlit run app.py
명령어를 실행하면 웹 브라우저에서 자동으로 앱이 열리며, 터미널에 표시된 URL(예: http://localhost:8501)로 접속하여 사용할 수도 있습니다.
